AI RESUME ANALYZER
Python · Streamlit · NLP · Plotly · FPDF2
GitHub: github.com/YOUR_USERNAME/ai-resume-analyzer

Built an end-to-end AI-powered web application that analyzes resumes against
specific job roles and calculates an ATS (Applicant Tracking System) compatibility
score. The tool extracts text from PDF/DOCX resumes using PyPDF2 and python-docx,
performs keyword-based NLP skill matching across 6 tech job roles (Data Scientist,
AI Engineer, Full Stack Developer, etc.), and generates a weighted ATS score out
of 100 using a custom multi-factor algorithm. Results are displayed through
interactive Plotly visualizations including gauge meters, radar charts, and bar
charts. Users can download a fully formatted PDF report of their analysis.

Key Technical Highlights:
• Implemented a weighted scoring engine (skill match 60%, structure 15%,
  action verbs 15%, keyword density 10%) for realistic ATS simulation
• Built a skill taxonomy database of 150+ skills across 6 job roles
• Designed responsive dark-theme UI with custom CSS in Streamlit
• Integrated FPDF2 for programmatic PDF report generation

🚀 Excited to share my latest project: AI Resume Analyzer! 🎯

I built a complete, open-source web application that helps job seekers understand
exactly how well their resume matches a target job role — and what to improve.

🔍 What it does:
✅ Upload your resume (PDF or DOCX)
✅ Select your target role (Data Scientist, AI Engineer, Full Stack Dev & more)
✅ Get an ATS Score out of 100 with a gauge meter
✅ See matched vs missing skills by category
✅ View radar charts, bar charts, and donut charts
✅ Receive personalized improvement suggestions
✅ Download a full PDF analysis report

• Python + Streamlit (web app)
• PyPDF2 + python-docx (resume parsing)

• FPDF2 (PDF report generation)
